Option gallery

Every row below is a live example. The short note explains the visual effect; the snippet shows the relevant configuration.

btnClass
Apply any Bootstrap button classes to match the surrounding interface.
{ btnClass: 'btn-outline-success' }
btnEmptyText
Set the label shown when a nullable select has no value.
{ btnEmptyText: 'Choose a value...' }
btnWidth
Keep controls aligned by giving the toggle a predictable width.
{ btnWidth: '240px' }
btnSplit
Separate the value button from the dropdown trigger for action-heavy toolbars.
{ btnSplit: true }
dropDirection
Choose the opening direction when space below the control is limited.
{ dropDirection: 'dropup' }
dropIconClass
Replace the default chevron with an icon that matches the control's purpose.
{ dropIconClass: 'bi bi-funnel-fill' }
searchText
Customize the search placeholder to make the expected input obvious.
{ searchText: 'Find a country...' }
showMultipleCheckboxes
The multi-select target below switches its selection indicator.
Use checklist controls when users need to scan many selected values quickly.
{ showMultipleCheckboxes: true }
showSelectionAsList
The target below switches between selected labels and a count.
Show selected labels in the button instead of only a count.
{ showSelectionAsList: true }
selectAllOnInit
Start a multi-select with every enabled option selected.
{ selectAllOnInit: true }
menuPreHtml / menuAppendHtml
Updates both HTML insertion points on the target menu.
Add contextual content before or after the option list.
{ menuPreHtml: '<strong>Choose a plan</strong>' }
menuMaxHeight
The target below contains enough items to make the scroll area visible.
Constrain long lists to a compact scrolling menu.
{ menuMaxHeight: 150 }
value
Preselect an option during the first initialization.
{ value: 'team' }
nullable
Keep a single select from becoming empty when a value is required.
{ nullable: false }
showSubtext
Display supporting metadata below the main option label.
{ showSubtext: true }
showActionMenu
The target below is the multi-select that receives the setting.
Expose Select All and Select None actions above a multi-select.
{ showActionMenu: true }
actionMenuBtnClass
Choose a class for the target below.
The setting selector is single-valued; it updates the bulk-action buttons on the multi-select target.
{ actionMenuBtnClass: 'btn-outline-success' }
menuClass
Style the outer dropdown menu container.
{ menuClass: 'shadow-lg rounded-4' }
menuInnerClass
Change the spacing and surface of the scrollable menu content.
{ menuInnerClass: 'p-3' }
menuItemClass
Apply Bootstrap utility classes to every dropdown item.
{ menuItemClass: 'text-primary fw-semibold' }
search
Show or hide the search field in this dropdown.
{ search: true }
animatedMenu
Animate the menu when it opens.
{ animatedMenu: true }
checkedIcon
Replace the selected-item icon with any Bootstrap Icons class.
{ checkedIcon: 'bi bi-star-fill' }
formatItem
Format each dropdown item with custom markup.
formatItem($option, title, subtext)
formatSelectedText
Format the selected value shown in the button.
formatSelectedText(title, subtext)
showSelectedText
Customize the summary shown when several values are selected.
showSelectedText: (count, total) => ...
